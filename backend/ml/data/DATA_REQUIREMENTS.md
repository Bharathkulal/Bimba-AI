# ML Dataset Requirements

## Task: Resume Quality / ATS Prediction

### Current Status: BLOCKED

**Model training is currently blocked.** 

### Reason
The existing ATS scores in the database are generated by a deterministic rule-based engine (`ATSEngine`). Using a deterministic score as a target for a Machine Learning model is circular and provides no generalization benefits over the rule-based engine itself. We need trustworthy, human-labeled data to train a model that can genuinely predict resume quality.

### Required Data
- **Task**: Supervised learning for Resume Quality Prediction
- **Required records**: Minimum 5,000 uniquely authored resumes.
- **Required fields**: 
  - Parsed Resume sections (Skills, Experience, Education, Projects).
  - Textual descriptions for each section.
- **Required labels**: 
  - Trustworthy human/expert rating (e.g. 1-100 score, or categories like "Poor", "Good", "Excellent") evaluated by professional recruiters or verified ATS placement outcomes.
- **PII requirements**: All names, emails, phone numbers, addresses, and identifying URLs must be scrubbed prior to feature extraction.

### Potential Data Sources
- Recruiter evaluations of existing Bimba AI platform resumes.
- Open-source HR datasets containing resume evaluations (ensure proper commercial licensing).

Model training (Phase 12) must not proceed until a suitable dataset is acquired and formatted according to the pipeline manifest schemas.
